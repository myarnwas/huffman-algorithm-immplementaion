# Huffman Coding Implementation

## Overview
This project implements the Huffman Coding algorithm, which is a lossless data compression technique. It assigns variable-length binary codes to characters based on their frequencies in the input data, with more frequent characters getting shorter codes.

## Usage
- Build a frequency table of characters from the input text.
- Construct a Huffman tree from the frequency table.
- Generate Huffman codes by traversing the tree.
- Encode the text into a compressed binary string.
- Decode the compressed string back to the original text.

## Applications
Huffman coding is widely used in file compression formats such as ZIP, GZIP, JPEG, and MP3, helping reduce the file size without losing any information.

Run the Python script to see encoding and decoding in action with a sample input.
